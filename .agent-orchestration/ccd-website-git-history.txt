## 78a4589 — 2026-08-06
Absorb The 4th Brew: story, brewing guide, and storefront

The 4th Brew is CCD's coffee brand but lived entirely on its own Shopify
site, surfaced here only as a partner logo that linked away. It now has
three first-class pages on ccdgroup.org, with Shopify demoted to a catalog
and checkout backend.

New routes (all through the existing [slug] route — no new route files):
  /4th-brew   the brand story, tied back to CCD's workforce programs
  /shop       the three roasts, live prices, add-to-cart
  /brewing    the eight-method brewing guide

No Buy Button, no SDK, no dependencies. Shopify's JS Buy SDK was deprecated
in Jan 2025 and lost support Jan 1 2026, and with three products it was
never the smaller option anyway. Instead:

  - BrewProducts fetches {brewShop}/products.json at build time (public,
    unauthenticated, revalidated hourly) so price and stock cannot drift.
  - "Add to cart" is a plain <a> to a Shopify cart permalink,
    {brewShop}/cart/{variantId}:1, which opens checkout with the item.
  - siteData owns the editorial (which coffees, described how); Shopify owns
    the commerce. Merged by handle.
  - If the fetch fails the build falls back to captured variant data rather
    than breaking — verified by building against an unreachable host.

Brand skin is token reassignment, not new components. `brand: "brew"` on a
page puts `.brew` on <main>, which overrides --green/--gold/--font-head
inside it. The CCD header and footer sit outside <main> and are unchanged.
Teal #108474 is 4.59:1 on white and safe as text; tan #c2b27f is 2.11:1 and
is used only as a fill behind ink, matching the existing rule for CCD gold.

Also:
  - Card gains optional `bullets`, rendered as a spec list. The brewing
    guide needs scannable grind/temp/ratio lines, not a paragraph.
  - PartnerWallSection no longer forces target="_blank" on every partner
    card. Partners CCD hosts itself now carry an internal path, and those
    must open in the same tab.
  - Aliases cover the old Shopify paths (/collections, /coffee-brewing-
    methods) so inbound links survive the domain retirement.

siteConfig.links.brewShop must stay pointed at Shopify's PRIMARY domain —
Shopify 301s every cart link to whatever that currently is. Move the primary
to shop.the4thbrew.com before retiring the4thbrew.com, or checkout breaks.
