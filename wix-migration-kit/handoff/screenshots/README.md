# Screenshots

`EDITOR-HANDBOOK.md` links to images in this folder. They are not taken yet — that needs someone with the Wix Editor open.

## Naming

Use the exact filename the handbook already references. Find them with:

```bash
grep -o "screenshots/[a-z0-9-]*\.png" ../EDITOR-HANDBOOK.md
```

## How to take them

- Screenshot the **whole Wix panel** in context, not a cropped button. Staff need to recognise the screen they are on.
- Draw a single arrow or box on the one thing being pointed at. One mark per image.
- Do not capture anything with a real person's private data — form submissions, member details, email addresses. If a real record is on screen, use a made-up one first.
- PNG. Roughly 1200px wide is plenty.

## Better than screenshots

For the five most common tasks (add a news post, add a team member, add an event, change page text, swap a photo), record a 3–5 minute screen video instead and link it at the top of that task's section. Nontechnical people follow video and skim documents. Screenshots are the fallback, not the goal.

Put the video links in `EDITOR-HANDBOOK.md` under each task heading. Host them wherever the org already keeps files — the point is that the link still works in three years, so use the org account, not a personal one.
