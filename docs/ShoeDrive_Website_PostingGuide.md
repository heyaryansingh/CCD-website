## PART 4 — HOW TO DO THIS IN WIX (Step-by-Step)

### STEP 1 — Log In
1. Go to **manage.wix.com** and log in with CCD's account credentials
2. Click **Edit Site** on ccdgroup.org

---

### STEP 2 — Upload Images & Files to Wix Media Manager

Before you add anything to the page, upload all media first.

1. In the Wix Editor, click **Media** (camera icon in the left sidebar)  
   OR go to **Media Manager** from the dashboard
2. Click **Upload Media** → **Upload from Computer**
3. Upload these files:
   - `Summer-Support-Our-Summer-Fundraiser.png` ← Banner image
   - `DonationBox_v01.png` ← Donation box photo
   - `shoes1.webp` ← Shoe pile photo 1
   - `shoes2.webp` ← Shoe pile photo 2
   - `shoes3.webp` ← Shoe pile photo 3
   - `flyer_takeaway_graphic_v01.jpg` ← "Shoe Us the Love" header graphic
   - `F2OWhyShoes.pdf` ← Background PDF for download link
4. Organize them into a folder — click **New Folder** and name it `Shoe Drive 2026`

---

### STEP 3 — Navigate to the Events Page

**Option A: Use Wix Events App (Recommended — cleanest)**
1. In the left sidebar, click **Add Apps** → search for **Wix Events** (it may already be installed)
2. From the Wix Dashboard (not the editor), go to **Events** in the left menu
3. Click **+ Create Event**
4. Fill in:
   - **Event Name:** Summer Fundraiser Shoe Drive
   - **Event Type:** Select "In-Person" or "Ongoing" (since it runs for 6 weeks)
   - **Start Date:** June 8, 2026
   - **End Date:** July 24, 2026
   - **Location:** Cooperative Community Development, Inc., 4003 Frederick Avenue, Baltimore MD 21229
   - **Description:** Paste the body text from Part 3 above
5. Upload `Summer-Support-Our-Summer-Fundraiser.png` as the event cover image
6. Click **Publish**

**Option B: Create a New Page (if not using Wix Events)**
1. In the Wix Editor, click **Pages** in the left sidebar
2. Click **+ Add Page** at the bottom of the page list
3. Name it: `Shoe Drive`
4. Choose a blank layout or a simple content layout
5. Proceed to Step 4

---

### STEP 4 — Build the Page Content

Work top to bottom. Add each element using the **Add (+)** button in the left sidebar:

**A. Hero Banner**
1. Click **Add (+)** → **Image**
2. Select `Summer-Support-Our-Summer-Fundraiser.png` from your media
3. Resize to full width (drag the handles to stretch edge-to-edge)
4. Optionally: click the image → **Settings** → set as a strip background instead

**B. Headline & Subheadline**
1. Click **Add (+)** → **Text** → **Title** (large heading)
2. Type: `Summer Fundraiser Shoe Drive`
3. Add another Text → **Subtitle**: `Clean Out Your Closet & Help Build the Center for Social Impact`

**C. Main Body Text**
1. Click **Add (+)** → **Text** → **Paragraph**
2. Paste the "The Ask" text from Part 3
3. Add another Text block for "The Impact" paragraph

**D. Drop-Off Location Cards**
1. Click **Add (+)** → **Strip** → choose a 2-column layout
2. In the left column: type CCD drop-off details
3. In the right column: type Catonsville Co-op Market details
4. Style both columns with a light background color (suggestion: light green `#E8F0E0`)
5. Add a map pin emoji 📍 before each location name

**E. Photo Gallery**
1. Click **Add (+)** → **Gallery**
2. Select "Grid Gallery" or "Slideshow"
3. Upload / select `shoes1.webp`, `shoes2.webp`, `shoes3.webp`
4. Add caption: "Every pair makes an impact"

**F. Donation Box Image**
1. Click **Add (+)** → **Image**
2. Select `DonationBox_v01.png`
3. Resize to a reasonable size (not full-width — maybe 350px wide, centered)
4. Add a caption text below: "Look for our Shoe Us the Love donation boxes!"

**G. Contact / CTA Section**
1. Click **Add (+)** → **Strip** — choose a colored background (CCD gold or green)
2. Add a **Text** block: questions contact info
3. Add **Text**: hashtags
4. Optionally add a **Button**: "Share on Facebook" → link to CCD Facebook page

**H. PDF Download Button**
1. Click **Add (+)** → **Button**
2. Label: `Learn Why Shoes Make a Difference (PDF)`
3. Click **Link** → **Document** → select `F2OWhyShoes.pdf` from your media
4. Style button as an outline/secondary button (not the main CTA color)

---

### STEP 5 — Add a Homepage Announcement (URGENT — event starts now)

Since collection boxes are available starting today, also add a notice on the homepage:

1. In the Editor, navigate to the **Home** page
2. Scroll to the top (below the main hero, if possible) or look for a **Ticker/Announcement Bar**
3. Click **Add (+)** → **Strip** → add a thin colored strip (gold background)
4. Add text: `🎉 Shoe Drive Fundraiser: June 8 – July 24! Drop off gently worn shoes at CCD (Tuesdays 12–3PM) or Catonsville Co-op Market (Tuesdays 4:30–8PM). [Learn More →]`
5. Link "Learn More" to the Shoe Drive event page
6. **Alternative:** Click the existing header/nav area → look for an **Announcement Bar** option (many Wix templates have this built in under **Menus & Pages** → **Announcement Bar** → toggle ON)

---

### STEP 6 — Add to the Navigation (if using Option B — standalone page)

1. In the Editor, click **Menus & Pages** in the left sidebar
2. Under your main navigation, click **+ Add Page** or drag the new `Shoe Drive` page into the menu
3. Or: add it as a sub-item under **Events** if that menu exists

---

### STEP 7 — Mobile Check

1. In the top toolbar, click the **mobile phone icon** to switch to mobile preview
2. Make sure:
   - The banner image is readable on mobile
   - Drop-off location cards stack vertically (not side by side)
   - Text is large enough to read
3. Click any element → **Mobile** tab in the inspector panel to adjust mobile-only sizing if needed

---

### STEP 8 — Publish

1. Click the blue **Publish** button in the top-right corner
2. Confirm the page is live by visiting ccdgroup.org in an incognito window
3. Copy the direct URL to the event page (e.g., `ccdgroup.org/shoe-drive-2026` or whatever Wix auto-generates) and share it in a reply to Tracy's email and on CCD's social accounts
