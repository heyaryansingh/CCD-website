SECTION 5

SEO & Analytics

SEO SETUP IN WIX
1.Set page title + meta description for every page via SEO Settings in the Wix Editor sidebar.
2.Enable Wix SEO Wiz — it auto-generates sitemap.xml and handles canonical URLs.
3.For CMS Dynamic Pages, set the SEO Pattern using the collection field: e.g. /events/{title-slug}
4.Add Open Graph image for each page (use hero photos from media/ folder).
5.Add Google Search Console verification code via Settings → SEO → Google Search Console.
ANALYTICS & TRACKING
1.Connect Google Analytics 4 via Settings → Tracking & Analytics → + New Tool.
2.Track form conversions: use Wix's built-in Conversion Tracking for each Wix Form submission.
3.Add Facebook Pixel if running paid social campaigns (Settings → Tracking → Meta Pixel).
4.Enable Wix Analytics dashboard — shows page views, top sources, and form completions in plain English, no code.
SECTION 6

Media & Assets

PHOTOS READY TO USE All photos in media/ folder are optimized JPEGs. Upload to Wix Media Manager → Images.
VIDEOS — ACTION NEEDED Drone footage exceeds 30MB upload limit. Compress to <20MB each or host on YouTube/Vimeo and embed via Wix Video widget.
LOGO Use media/ccd-logo.png (PNG with transparency). Upload to Wix Media Manager → used in Header component.
Tip for Johnny / no-code editors: To update a photo anywhere on the site in Wix Studio, click the image → Change Image → choose from Media Manager. Images in CMS collections (Events, News, Projects, Team) update automatically everywhere that item appears — you only need to update it once.
